# debugging-app-practice

## 概要
COACHTECH 教材 Tutorial 10-4「デバッグ ハンズオン演習」で作成した成果物です。

## 使用技術
- PHP 8.x
- Laravel 10.x
- デバッグツール（`dd()`, `dump()`, `Log` ファサード）

## 学んだこと
- エラーメッセージを読んで問題を特定する
- $fillableを設定してエラーを修正する
- 応用）ログ出力をミドルウェアに移動する

## 動作確認
ブラウザで確認。エラーを解析・修正した後、ログインしてアクセス送信。

## 手詰まりになったこと
何度やってもエラー画面地獄から抜けられずにいたが、sampleを見ながら一つ一つ見直していたら、コードがかぶっていることに気づき修正したら、正常に起動できた。
